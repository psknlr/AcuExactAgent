01 / 先确认目标文章，再批量提取

依据 EndNote 记录确定目标文章，并在区域清单中标注页面与边界框。批处理清单的每项对应 PDF 和文章清单。

python -m acuexact inspect --pdf paper.pdf --out outputs/inspection --title "目标文章标题" python -m acuexact batch --manifest batch.json --out outputs/batch

02 / 对照人工金标准，报告实际指标

使用相同文章范围的人工标注检查漏提、错字与出处字段。当前演示不含用户金标准，准确率须在获得标注后实测。

python -m acuexact evaluate --pred outputs/paper/result.json --gold gold.json --out outputs/evaluation.json python -m acuexact demo --out outputs/demo
