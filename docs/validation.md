# 验证记录

本次实现于 Windows / Python 3.12 环境验证，核心依赖锁定为 pdfplumber 0.11.9、pypdf 6.10.0、openpyxl 3.1.5。仓库配置 Ubuntu/Windows 与 Python 3.10/3.12 的 GitHub Actions 矩阵；远端运行状态以 Actions 页面为准。

## 已执行

- `python -m unittest discover -s tests -v`：**43 项通过**，覆盖字符保真、出处错误倒填、出处跨行、残缺引号恢复、重复及跨页引文、同页区域隔离、哈希/重叠校验、EndNote唯一ID、ZIP路径、空gold、部分标注、检索证据、模型结构化响应与本地HTTP。
- `python -m acuexact demo`：8 条合成 gold 全部匹配，2 条精确病名排除；原文明示出处比较无误加、无错配。仅是合成回归结果，不是实际医学文献指标。
- Editable 包安装成功，虚拟环境内再次运行 demo 成功。该虚拟环境复用预装依赖，未声称完成所有操作系统的全新依赖安装测试。
- 浏览器访问实际本地 HTTP 服务成功；核查响应式页面布局、8条演示结果、弱相关筛选为3条且保留重复句、自定义输入提取2条/排除1病名、跨行出处与前后引用不串配。
- 七组各一份真实PDF页面读取成功；三份原始零页文件通过备用解析器归一化后读取成功。
- SinoMed 同页上下两篇的版面实验：目视后圈定下半页三栏，取得3条候选，上半页邻文标题不在选区文本中；仍有引号不平衡告警，**不得称为完整或准确提取**。
- 中文维基文库真实联网烟测执行成功，最多3请求取得匹配页面并保留版本ID。命中的汇编页面仍标记“候选待核证”，不会自动当作原始出处。
