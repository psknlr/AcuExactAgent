# 验证记录

0.2.0 于 Windows / Python 3.12 环境验证，核心依赖锁定为 pdfplumber 0.11.9、pypdf 6.10.0、openpyxl 3.1.5、jsonschema 4.26.0。仓库配置 Ubuntu/Windows 与 Python 3.10/3.12 的 GitHub Actions 矩阵；远端运行状态以 Actions 页面为准。

## 已执行

- `python -m unittest discover -s tests -v`：**123 项通过**。保留原版43项，新增28项供应商协议与错误测试、30项智能体状态/证据/预算测试、22项 PDF/任务/HTTP 集成测试。模型响应均由 fake 或 mock 提供，未调用真实付费 API。
- 新增覆盖：GPT/Claude/MiniMax/custom请求格式、JSON Schema及一次修复、429/5xx有限重试、拒绝/截断、密钥不泄漏、视觉能力边界；多篇选择、越界/重叠区域拒绝、伪造引文拒绝、批量ID完整性、API失败保留引文、跨供应商HTTP预算及取消、视觉冲突不覆盖原文、同PDF不同文章ID；真实临时PDF上传/渲染与完整fake模型工作流。
- `python -m acuexact demo`：8 条合成 gold 全部匹配，2 条精确病名排除；原文明示出处比较无误加、无错配。仅是合成回归结果，不是实际医学文献指标。
- Editable 包安装成功，虚拟环境内再次运行 demo 成功。该虚拟环境复用预装依赖，未声称完成所有操作系统的全新依赖安装测试。
- 浏览器访问实际本地 HTTP 服务成功；核查响应式页面布局、8条演示结果、弱相关筛选为3条且保留重复句、自定义输入提取2条/排除1病名、跨行出处与前后引用不串配。
- 0.2.0 独立 headless Edge 完成 **10项** UI 检查：真实 PDF 上传/预览、供应商和辅助视觉切换、页码校验、缺key明确400、离线筛选与TSV导出、待复核/取消部分结果展示、桌面及390px手机布局。后两种任务结果使用明确的模拟HTTP响应；没有JS错误、没有外部浏览器请求、没有真实模型调用。
- 七组各一份真实PDF页面读取成功；三份原始零页文件通过备用解析器归一化后读取成功。
- SinoMed 同页上下两篇的版面实验：目视后圈定下半页三栏，取得3条候选，上半页邻文标题不在选区文本中；仍有引号不平衡告警，**不得称为完整或准确提取**。
- 中文维基文库真实联网烟测执行成功，最多3请求取得匹配页面并保留版本ID。命中的汇编页面仍标记“候选待核证”，不会自动当作原始出处。

## 尚不可验证

- 人工 gold 未提供，真实提取 precision/recall/F1 与强弱相关分类效果不可用。
- EndNote 真实记录未提供，尚未验证完整的真实记录到文章映射；XML/RIS接口使用合成导出记录测试。
- 未运行真实 GPT、Claude 或 MiniMax 模型；核对官方API规范并模拟响应不等于验证用户账户权限、远端模型可用性或文献处理质量。
- 当前机器未配置 Tesseract 中文OCR，真实OCR识别性能未测试。
- Docker 配方已提供，未在本机执行 Docker 构建。

所有失败与待审状态应在后续真实实验中计入报告。不能用合成回归、成功解析率或已匹配引文的分类准确率替代端到端效果。
